# BeeWave Shared Agent Workspace

`.agents/shared/` is the canonical, tool-neutral source of knowledge for AI-assisted work here.

- Read `shared/agent-startup.md` first.
- Stable facts and decisions go in `shared/memory/`.
- Non-negotiable coding/operating rules go in `shared/rules/`.
- OpenSpec workflow skills live in `skills/openspec-*` (propose -> apply -> archive).
