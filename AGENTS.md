## Project Context

**BeeWave**: Rust firmware for an ESP32-WROOM (4 MB, classic Xtensa) controlled from a Web Bluetooth PWA.
Hexagonal core + feature slices (see `docs/ARCHITECTURE.md`):
- `crates/protocol`: wire types + postcard codec (`no_std`). Source of truth for the wire format.
- `crates/core`: domain, ports, `App` service, `features/{radio,scan,status,ota,settings,auth}` (`no_std`, host-tested).
- `firmware/`: ESP-IDF adapters + composition root (`main.rs`). Own cargo workspace, Xtensa target.
- `web/`: Vite + TS PWA, `features/*` slices, `shared/` kernel (codec, `Transport` port, context).

## Non-Negotiable Invariants

1. **Dependency rule:** `adapters -> core -> protocol`. `crates/core` never imports `esp-idf-*`, `std` threads, or allocates (heapless only).
2. **Features are isolated:** slices depend on `ports`/`shared`, never on each other; only `App` / `main.ts` compose them.
3. **Wire format changes touch three places:** `crates/protocol` -> `make vectors` -> `web/src/shared/protocol/`. `make test` must stay green.
4. **Telemetry is lossy, commands are validated:** the BLE sink never blocks; every command is range-checked in the core.
5. **No secrets in the repo;** commands require an authenticated session (HMAC with a 32-byte device key). By default the device is *unclaimed* until the first client provisions its own key (stored in NVS, see `openspec/changes/auto-claim-device`); `make fw-*` `FW_KEY=file` bakes in the untracked `firmware/.beewave-key` instead; `make fw-unclaim` resets a claimed device. A claimed device accepts no other key. Firmware updates must be Ed25519-signed (`BEEWAVE_OTA_PUBKEY`, private key untracked in `firmware/.beewave-ota.pem`).
6. **Memory is a budget:** few long-lived tasks, bounded channels, no unbounded `Vec`/`String` on the device path.
7. **Git hygiene:** never add AI attribution (no `Co-Authored-By`, no "generated by" lines) and always commit as the machine's own git user; see `.agents/shared/rules/git.md`.
8. **Web tooling is pnpm only:** use `pnpm` (pinned via `packageManager`, lockfile `web/pnpm-lock.yaml`); never `npm` or `yarn`. Declare every import as a dependency (pnpm is strict); allow install scripts only via `allowBuilds` in `web/pnpm-workspace.yaml`.
9. **File structure:** one concern per file, `index.ts`/`mod.rs` only re-export, tests in their own file; see `.agents/shared/rules/file-structure.md`.
